# Dark Hub Gold

واجهة عربية بلمسة سوداء وذهبية، مبنية كموقع static من دون framework أو dependencies خارجية للواجهة الرئيسية.

## التشغيل والنشر السحابي

افتح index.html محليًا، أو انشر محتويات هذا المجلد على GitHub Pages أو Cloudflare Pages. لا تنشر المجلد داخل مجلد فرعي إذا كنت تريد أن يعمل الرابط الجذري تلقائيًا؛ استخدمه كـ document root. مع GitHub Pages، ارفع الملفات إلى جذر المستودع، ثم اختر النشر من الفرع والمجلد المناسبين في Settings > Pages، وفعّل HTTPS.

## البنية

- index.html: الواجهة الرئيسية والتنقل الموحد.
- css/site.css: تنسيق الواجهة الرئيسية.
- css/features.css: skin موحد للصفحات التفاعلية.
- css/pages/: تنسيقات الصفحات الأصلية بعد فصلها عن HTML.
- js/app.js: التنقل والتحميل داخل إطار التجربة.
- js/pages/: منطق الألعاب والأدوات الأصلي بعد فصله عن HTML.
- pages/: صفحات الخلفيات والألعاب والأدوات.
- .nojekyll: يمنع المعالجة غير المطلوبة من Jekyll عند النشر على GitHub Pages.

الصور وبعض خدمات التحميل ما زالت تستخدم مصادرها الخارجية كما في الموقع الأصلي.

## الأمان

الموقع static ولا يحتوي على خادم أو قاعدة بيانات أو مفاتيح سرية في الواجهة. ملفات HTML وCSS وJavaScript التي يحمّلها المتصفح تكون عامة ويمكن الاطلاع عليها؛ لا تضع مفاتيح API أو كلمات مرور فيها. إذا احتاجت ميزة مستقبلًا إلى سر أو صلاحية خاصة، ضعها خلف خدمة backend محمية. لا توجد استضافة تضمن استحالة الاختراق.
